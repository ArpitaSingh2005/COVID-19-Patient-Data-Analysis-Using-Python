# COVID-19 Patient Data Analysis Using Python

## Project Overview
This project analyzes COVID-19 patient data using Python. The dataset was cleaned, explored, and visualized to understand patient demographics, patient status, age distribution, regional trends, and confirmed cases through Exploratory Data Analysis (EDA).

## Objectives
- Clean and preprocess the COVID-19 dataset.
- Perform Exploratory Data Analysis (EDA).
- Visualize important trends using charts.
- Identify meaningful insights from the data.

## Dataset
- COVID-19 Patient Dataset
- File: `patient.csv`

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Data Preprocessing
4. Exploratory Data Analysis (EDA)
5. Data Visualization
6. Conclusion

## Visualizations
- Gender Distribution
- Age Distribution
- Patient Status Distribution
- Monthly Confirmed Cases
- Region-wise Cases
- Infection Cases Analysis
- Correlation Heatmap

## Key Findings
- Most patients belonged to the adult age group.
- The dataset contained significantly more isolated patients than released or deceased patients.
- Cases varied across different regions.
- Data cleaning improved the quality of analysis.

## Conclusion
This project demonstrates how Python can be used for data cleaning, exploratory data analysis, and visualization to extract meaningful insights from real-world COVID-19 patient data.
